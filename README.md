# Biblioteca America

**Versión:** v0.1.0 (ver [`CHANGELOG.md`](./CHANGELOG.md) y
[`ROADMAP.md`](./ROADMAP.md))

Catálogo de cómics estadounidenses y canadienses que **no** pertenezcan a
los universos compartidos de las grandes editoriales americanas (Marvel,
DC, Image, etc.), dentro del proyecto "Biblioteca" de elyini. Detalle del
alcance en [`CLAUDE.md`](./CLAUDE.md).

Coordinación central del proyecto: `elyini/Biblioteca_Documentacion`
(rol, versionado, gobernanza y protocolo de comunicación entre
bibliotecas — no lo dupliques aquí, enlázalo).
